Amenity Type — wired into RHF + Zod

Consistent with amenityName/amenityDescription; keeps the "locked once created" behavior

RuleWhere it's enforced
Mandatory overallzod schema: .refine(val => val !== null)
Can be null while creating (before a pick)zod type stays number | null, only fails validation on submit if still null
Mandatory / can't change once createdyour existing pattern kept: amenityId present → render read-only text instead of the select at all

1. Schema — add the required-when-submitted rule

src/modules/amenities/lib/general-info-schema.ts 
import { z } from 'zod';

export const generalInfoSchema = z.object({
  amenityTypeId: z
    .number({ invalid_type_error: 'Amenity Type is required' })
    .nullable()
    .refine((val) => val !== null, { message: 'Amenity Type is required' }),
  amenityName: z
    .string()
    .trim()
    .min(1, 'Name is required')
    .max(120, 'Keep it under 120 characters'),
  amenityDescription: z
    .string()
    .trim()
    .max(500, 'Keep it under 500 characters'),
});

Type stays number | null (nothing else in your types needs to change) — the refine only affects validation timing, not the TypeScript shape of GeneralInfoValues.

2. GeneralInfoFields.tsx — Controller-wired select

src/modules/amenities/components/GeneralInfoFields.tsx 
'use client';

import { useForm, Controller } from 'react-hook-form';
import { zodResolver } from '@hookform/resolvers/zod';
import { Input } from '@hlt/react-component-library';
import type { AmenityType, GeneralInfoValues, GeneralInfoValuesWithId } from '@/types/amenities';
import { generalInfoSchema } from '../lib/general-info-schema';

interface Props {
  values: GeneralInfoValues;
  onChange: (values: GeneralInfoValues) => void;
  error?: string;
  amenityTypes: AmenityType[];
  amenityId?: number;
}

export function GeneralInfoFields({
  values,
  onChange,
  error,
  amenityTypes,
  amenityId,
}: Props) {
  const {
    control,
    formState: { errors },
  } = useForm<GeneralInfoValues>({
    resolver: zodResolver(generalInfoSchema),
    values,
    mode: 'onChange',
  });

  const amenityTypeName =
    amenityTypes.find((t) => t.amenityTypeId === values.amenityTypeId)
      ?.amenityTypeName || 'General Admission';

  return (
    <div className="flex flex-col gap-4">
      {error && <p className="text-sm text-red-600">{error}</p>}

      <div className="flex flex-row gap-4">
        <div className="flex flex-col gap-1 mb-2 max-w-md w-1/2">
          <label className="text-sm font-medium text-gray-700 mb-1">
            Amenity Type
          </label>

          {amenityId ? (
            <p className="font-bold">{amenityTypeName}</p>
          ) : (
            <Controller
              name="amenityTypeId"
              control={control}
              render={({ field }) => (
                <select
                  className="w-full rounded-md border border-gray-300 bg-white px-3 py-2 text-sm text-gray-900 focus:outline-none focus:ring-1 focus:ring-blue-500 disabled:bg-gray-100 disabled:cursor-not-allowed h-11"
                  value={field.value ?? ''}
                  onChange={(e) => {
                    const next = e.target.value === '' ? null : Number(e.target.value);
                    field.onChange(next);
                    onChange({ ...values, amenityTypeId: next });
                  }}
                  onBlur={field.onBlur}
                >
                  <option value="">Select...</option>
                  {amenityTypes.map((t) => (
                    <option key={t.amenityTypeId} value={t.amenityTypeId}>
                      {t.amenityTypeName}
                    </option>
                  ))}
                </select>
              )}
            />
          )}
          {errors.amenityTypeId && (
            <p className="text-sm text-red-600">{errors.amenityTypeId.message}</p>
          )}
        </div>

        <div className="w-1/2">
          <Controller
            name="amenityName"
            control={control}
            render={({ field }) => (
              <Input
                label="Amenity Name"
                placeholder="e.g. General Admission"
                className="w-full font-medium disabled:bg-gray-50 max-w-md text-black! border-gray-100!"
                name={field.name}
                value={field.value}
                onChange={(e) => {
                  field.onChange(e);
                  onChange({ ...values, amenityName: e.target.value });
                }}
                error={errors.amenityName?.message}
              />
            )}
          />
        </div>
      </div>

      <div className="flex flex-col gap-1">
        <label className="text-sm font-medium text-gray-700">
          Amenity Description
        </label>
        <Controller
          name="amenityDescription"
          control={control}
          render={({ field }) => (
            <textarea
              {...field}
              onChange={(e) => {
                field.onChange(e);
                onChange({ ...values, amenityDescription: e.target.value });
              }}
              className="w-full rounded-md border border-gray-300 px-3 py-2 text-sm"
              rows={4}
            />
          )}
        />
        {errors.amenityDescription && (
          <p className="text-sm text-red-600">{errors.amenityDescription.message}</p>
        )}
      </div>
    </div>
  );
}
what changed

Removed: amenityTypeId and setSelectedAmenityTypeId props — they duplicated state that values + RHF's values-sync option already own.

Added: Controller wraps the select exactly like the other two fields, so zodResolver validates it, and errors.amenityTypeId?.message now renders "Amenity Type is required" if left unselected.

Kept as-is: the amenityId ? <p>...</p> : <select> branch — this is still what enforces "can't change once created," it's just that the select branch is now validated instead of being plain local state.
